# చందమామ కథలు Reader

A simple, beautiful static website for reading Chandamama Telugu issues (1947–2002) directly in the browser.

## Features
- Browse all available issues by year and month
- Telugu month names
- In-browser PDF reader powered by PDF.js (page navigation, zoom, keyboard arrows)
- Direct download links
- Streams from Internet Archive — no need to host the 6GB of PDFs
- Dark theme with moon-inspired accents
- Mobile-friendly

## Files
- `index.html` — Main catalog browser
- `viewer.html` — PDF reader
- `chandamama_catalog.json` — Complete list of 646 issues with exact filenames and URLs

## Deployment
1. Upload these three files to any static host:
   - GitHub Pages
   - Netlify
   - Vercel
   - Cloudflare Pages
   - Or any web server

2. Open `index.html` in a browser.

## Source
All PDFs are from the Internet Archive collection:
https://archive.org/details/chandamama_telugu_all

## Disclaimer
This is an archival / educational project for cultural preservation. Content belongs to the original publishers. Early issues are likely in the public domain in India. Later issues have uncertain copyright status. We link to Internet Archive rather than rehosting.

## Gaps
Most years are complete. Notable gaps:
- 1947: July–December only (first issue)
- Some sparse months in late 1990s

The original uploader invites contributions of missing issues.
